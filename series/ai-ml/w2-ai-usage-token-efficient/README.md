# Workshop 2: AI Is Getting Expensive — Stop Wasting Tokens!

## 🎯 Overview

As AI coding assistants become more powerful with agentic capabilities, they're also becoming more expensive. This workshop teaches you how to work smarter with AI tools by understanding tokens, applying software engineering principles, and designing efficient workflows that deliver better results while reducing costs.

**Duration**: 1 hour

**Level**: Intermediate (Basic AI coding assistant experience required)

**Recording**: [Coming Soon]

## 📚 What You'll Learn

- Understand how LLMs work and what tokens actually are
- Recognize the evolution from simple prompts to agentic AI
- Apply software engineering principles to AI interactions
- Design token-efficient prompts and workflows
- Use divide-and-conquer strategies for complex tasks
- Leverage agentic skills for framework-specific tasks
- Work with AI like a senior developer delegating to a junior

## 🔧 Prerequisites

### Required Knowledge
- Basic experience using AI coding assistants (GitHub Copilot, Cursor, etc.)
- Understanding of software development workflows
- Familiarity with VS Code or similar IDE

### Required Tools
- GitHub Copilot or similar AI assistant with agentic capabilities
- VS Code (or IDE with AI integration)
- Git for version control

### Optional
- OpenAI API account (for understanding token pricing)
- Access to token counting tools

## 📋 Workshop Structure

### Part 1: Understanding the Foundation (15 mins)
- How LLMs actually work
- What are tokens and why they matter
- The evolution: prompts → chat → agents
- Why token usage is exploding

### Part 2: The Myth of the "Magic Prompt" (10 mins)
- Why perfect prompts don't exist
- The real cost of over-engineered prompts
- What actually works: clarity over cleverness

### Part 3: Software Engineering Principles for AI (15 mins)
- Divide and conquer for complex tasks
- Single responsibility principle for prompts
- Iterative refinement over perfect first tries
- The senior-junior delegation model

### Part 4: Token-Efficient Workflows (15 mins)
- Designing efficient prompt sequences
- Using agentic skills and tools effectively
- When to split vs. combine tasks
- Supervision strategies

### Part 5: Hands-On Practice (15 mins)
- Real-world scenarios
- Measuring and optimizing token usage
- Q&A and discussion

## 🎓 Learning Outcomes

By the end of this workshop, you will be able to:

1. ✅ Explain how tokens work and impact AI costs
2. ✅ Design prompts that minimize token waste
3. ✅ Break down complex tasks into efficient subtasks
4. ✅ Use agentic skills to avoid context overload
5. ✅ Apply delegation strategies for better AI collaboration
6. ✅ Measure and optimize your token usage
