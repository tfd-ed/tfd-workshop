Performance Metrics Demo

This page is intentionally crafted with real-world issues so you can observe each metric in Lighthouse and Chrome DevTools.

Run Lighthouse to score this page
🛠️ How to run
Option A — Browser DevTools (quickest)
  1. Open demo.html via a local server (see Option B)
  2. Press F12 → Lighthouse tab
  3. Select Performance only → Analyze page load
  4. Watch each metric light up below
Option B — CLI (recommended)
  1. Start a server: npx serve . -p 8080 or python3 -m http.server 8080
  2. Run: lighthouse http://localhost:8080/demo.html --view
📐 Core Web Vitals & Other Metrics
—
LCP

Largest Contentful Paint

When the largest visible element finishes loading.

Good: < 2.5 s
Needs improvement: 2.5 – 4 s
Poor: > 4 s
—
INP

Interaction to Next Paint

How fast the page responds to user input.

Good: < 200 ms
Needs improvement: 200 – 500 ms
Poor: > 500 ms
—
CLS

Cumulative Layout Shift

Unexpected visual movement during load.

Good: < 0.1
Needs improvement: 0.1 – 0.25
Poor: > 0.25
—
FCP

First Contentful Paint

When the first text or image paints on screen.

Good: < 1.8 s
Needs improvement: 1.8 – 3 s
Poor: > 3 s
—
TTI

Time to Interactive

When the page is fully interactive (main thread quiet for 5 s).

Good: < 3.8 s
Needs improvement: 3.8 – 7.3 s
Poor: > 7.3 s
—
TBT

Total Blocking Time

Sum of time the main thread was blocked > 50 ms.

Good: < 200 ms
Needs improvement: 200 – 600 ms
Poor: > 600 ms
